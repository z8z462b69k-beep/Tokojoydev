Prédiction d’admission – k-NN écrit à la main ▶

Python
Intelligence artificielle
Projet d’entraînement · données fictives
Algorithme des k plus proches voisins sans bibliothèque, validé par leave-one-out (86 % sur le jeu de données fictif). 
def knn(x, train, k=3):
    voisins = sorted(train, key=lambda d: dist(x, d[0]))[:k]
    return Counter(l for _, l in voisins).most_common(1)[0][0]
