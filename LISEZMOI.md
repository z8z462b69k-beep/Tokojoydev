# Portfolio – Joy Jongwane

- index.html : le portfolio (un seul fichier, s'ouvre dans le navigateur)
- projets/ : trois petits projets à publier sur GitHub (un dépôt par dossier)

## Mettre le portfolio en ligne gratuitement
1. GitHub Pages : créez un dépôt, envoyez index.html, puis Settings > Pages.
2. Ou glissez-déposez le dossier sur netlify.com/drop.

## Brancher vos dépôts GitHub
Dans index.html, cherchez `var GH_USER='';` et mettez votre pseudo GitHub.
Les dépôts doivent s'appeler : clinique-sql, centre-sante-cli, ia-knn-admission.
